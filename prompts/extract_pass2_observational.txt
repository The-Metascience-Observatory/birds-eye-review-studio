PROVENANCE — REQUIRED FOR EVERY *_quote FIELD:
Each number that feeds the meta-analysis has a companion `*_quote`. Copy 10-30
words of text VERBATIM from the paper — the exact sentence, or the table row,
that the number appears in. Character-for-character: do not paraphrase, do not
reformat numbers (keep "12.4 ± 3.1" as written, not "12.4 (SD 3.1)"), do not
translate, do not fix typos, do not join text that is not adjacent.
- If the value was CALCULATED from other reported values, quote the source
  values you calculated from and set the matching `*_source` to "calculated".
- If the value is genuinely absent from the text (figure-only, or not reported),
  set the quote to null and `*_source` to "not_reported". Do NOT invent a quote.
A quote that does not appear in the paper is an extraction failure and is worse
than no quote at all: these are checked mechanically against the source text.

CRITICAL RULES FOR DATA EXTRACTION:
1. ALWAYS extract per-arm means, SDs, and Ns for every outcome and timepoint — even when the paper also reports a between-group effect. These are the raw ingredients for computing pooled effect sizes.
2. For single-arm studies (case series, before-after with no control): there will be only ONE arm. Extract pre/post values at each timepoint. Use within_group_change to capture the pre-post difference with its p-value.
3. If the paper reports a between-group effect (mean difference, OR, RR, HR — adjusted or unadjusted), extract it verbatim with its CI and p-value. Set effect_source to "verbatim". PREFER adjusted estimates when both adjusted and unadjusted are available.
4. If per-arm means and SDs are available but NO between-group effect is reported, CALCULATE the mean difference (intervention minus comparator) and set effect_source to "calculated". Do NOT calculate SMD or Cohen's d.
5. For binary outcomes, extract events and total per arm. If the paper reports OR or RR, extract it. If not, leave between_group_effects as an empty array.
6. For time-to-event outcomes, extract HR with CI if reported.
7. Extract EVERY timepoint that has numeric data — baseline, intermediate, and final. Do not skip intermediate timepoints.
8. Extract BOTH endpoint values AND change-from-baseline when both are reported — use separate arm_results entries with different result_type values.
9. When the paper reports SE instead of SD, put it in the "se" field (leave "sd" as null). When 95% CI is given for per-arm values, use ci_95_low and ci_95_high.
10. If numeric outcome data appears ONLY in figures with no table or text values, set result_source to "not_reported" and note "data only in figures" in extraction_metadata.extractor_notes.

OBSERVATIONAL STUDY-SPECIFIC RULES:
11. For confounding control: record the adjustment_method and adjustment_variables in study_design. If the paper uses propensity score matching, record matching_method and the variables used.
12. For retrospective studies using medical records: note the data_source (e.g. "electronic health records", "insurance claims database").
13. For single-arm case series: set has_comparison_group to false, num_arms to 1. The key data will be pre-post within_group_change.
14. For studies with historical controls or external comparators: set the comparator group type to "historical_control" and note this in extraction_metadata.

OUTPUT SIZE MANAGEMENT — CRITICAL:
- You MUST return a single, complete, valid JSON object. NEVER truncate or split across responses.
- When all outcomes are requested, include every numerically reported outcome, even when it has only a p-value, F statistic, range, or no SD. Represent a reported between-group p-value with effect_measure/effect_value null when no effect estimate is available. Do not omit an outcome because its statistics are incomplete. Keep descriptive prose brief to preserve space for the results.
- For risk_of_bias, use the compact domain_judgments format (domain:judgment pairs). key_concern is ONE sentence about the most important bias issue.
- Keep subgroup descriptions brief; retain numerical subgroup outcomes when requested and label their synthesis_population explicitly.

OTHER RULES:
- Return separate outcome objects for distinct instruments, subscales, symptoms, and units. Raw scores and percentage changes must be separate outcomes with their own unit and analysis_basis; do not put a percentage change into a raw-score endpoint. Preserve every reported timepoint and result_type.
- For the arms array, arm_id=1 should be the treatment/intervention group. arm_id=2 should be the comparator (if any).
- Always extract each arm's mean, sd, and n_analyzed in arm_results when the paper reports them — these feed the standardized mean difference (Hedges' g). Do NOT compute SMD yourself.
- p_value_exact: true if the paper states an exact value (e.g. p=0.032), false if it states a threshold (e.g. p<0.05).
- For subgroup_analyses, only include what the paper explicitly reports. Use empty array if none reported.
- If a field is genuinely not reported in the paper, use null (not 0, not empty string).

SCIENTIFIC VALIDITY (applies to every result):
- Set is_primary true only when the paper explicitly identifies that outcome as primary, false for an explicitly secondary outcome, and null when the hierarchy is unstated. Do not infer outcome-level N from test degrees of freedom or the enrollment count.
- Populate synthesis_population with the actual clinical population and subgroup described for each outcome (for example adults meeting the stated diagnostic criteria). This is distinct from analysis_population, which identifies which enrolled participants were analyzed. Do not leave a known clinical population null.
- Set primary_timepoint_id to the assessment prespecified for that outcome in the paper. If there is exactly one non-baseline assessment, identify that assessment. For multiple assessments with no stated primary assessment, leave it null. Distinguish end-of-treatment assessment from later follow-up after stopping treatment; use on_treatment for assessment at treatment completion and post_treatment for subsequent follow-up.
- Percentage change is NOT a point change: make a distinct outcome with unit="percent change from baseline" and analysis_basis="change_from_baseline". Its arm results must retain mean_type, uncertainty_type, analysis_population, result_type and n_unit, just as endpoint results do. Never combine percentage changes with raw-point outcomes.
- Sample totals and per-arm Ns must refer to the groups analyzed in this report. Never add excluded parent-trial control groups to a cross-trial comparison. Use the N for the specific outcome and timepoint; do not copy the enrollment N to follow-up results. If that N is unstated, use null.
- Preserve censored range limits such as >44 with range_high_operator=">", and an exact limit with "=". Never silently treat a censored bound as exact.
- result_quote/effect_quote must be a contiguous verbatim span from the supplied text, not a reconstructed sentence. Never insert an arm header next to a cell or rewrite decimal commas inside a quote. Use source_location separately for table, row and column. A full original table row is preferable to joining nonadjacent snippets.
- Use range_low/range_high exclusively for reported minimum–maximum ranges; iqr_low/iqr_high exclusively for quartiles. Record dispersion_reported_as from the table caption or methods, or unstated if unspecified. Baseline demographics and symptom means are not post-treatment effects.
- Classify the allocation of the groups actually compared in THIS report, not the design of studies supplying its participants. Comparing treatment arms drawn from two separate randomized trials is a non-randomized comparison, unless participants were themselves randomized between those exact arms. Describe the parent trials separately; do not assign their randomization, allocation concealment, or RCT risk-of-bias rating to this cross-trial comparison.
- Use analysis_basis only as endpoint, change_from_baseline, model_based, paired, or unknown; put the statistical method in source_location/notes. Record analysis_population from the stated participant set (ITT, modified ITT, per-protocol, complete cases, or another explicitly described set); leave it null when unstated. Never infer ITT just because a study is randomized.
- A table caption or footnote determines whether parentheses contain SD, SEM, CI, range or IQR. Preserve ranges as ranges (never SD/CI), distinguish baseline from follow-up, and copy only the comparator-specific p-value. Keep a traceable quote and table/row/column location for every numeric result.
- Extract exact outcome identity, units, population/subgroup and assessment time. SBP and DBP, LDL and triglycerides, weight and liver enzymes are distinct outcomes even in the same domain.
- Preserve p-value operators (=, <, <=, >, >=) in p_value_operator. Never turn p<0.05 into an exact p=0.05. Keep ambiguous operators null.
- Bind each contrast to intervention_arm_id and comparator_arm_id, with result_type (endpoint, change_from_baseline, model_based, paired), analysis_population and source_location (page/table/row AND column headers).
- Label mean_type raw versus adjusted/least-squares, and uncertainty_type sd, se_mean, se_model, ci_mean or ci_model. A model-adjusted SE/CI is NOT a raw sample SD. If unknown, use unknown; do not guess.
- n_analyzed counts participants in THAT arm and outcome/timepoint. Never duplicate the whole-study N into each arm or substitute visits, measurements or clusters for participants. Record n_unit explicitly. A crossover participant can appear under both treatments; identify period/sequence and paired analysis.
- Source quotes for table values must include, or source_location must identify, the corresponding column headers. A matching number somewhere in the paper is insufficient.
- Set higher_is_better to null when clinical direction is unclear. A biomarker increase/decrease is not automatically benefit/harm. Never infer clinical benefit from statistical significance alone.
- Include all study arms and their actual comparisons. Identify placebo and active_comparator arms as such. Combination-product results do not establish an individual ingredient's effect.
- Prefer extraction of reported contrasts to model-generated calculations. Derived arithmetic is performed and labelled by the deterministic analysis layer.
- Include timepoint role (baseline, on_treatment, post_treatment, washout) and elapsed_hours for acute studies. Zero weeks does not mean baseline when measured after dosing.

- For crossover/cluster contrasts set design_adjusted true ONLY when the reported variance accounts for pairing/clustering. Cite the statistical methods. Otherwise null.

For a reported SMD, record standardization (pooled_within_arm_sd, baseline_sd, change_sd, or unknown) and unit="standard_deviation" only when source-verifiable. Do not infer a common smd_construct from a broad outcome domain.

Use synthesis_population for the source-defined clinical population/subgroup. Leave synthesis_time_window and smd_construct null unless an explicit protocol mapping is supplied; do not invent compatibility across studies. Mark primary_timepoint_id for an explicitly specified primary assessment, or the sole non-baseline assessment when only one is reported.
